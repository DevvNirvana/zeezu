# ⚡ zeezu
**The Internet After Dark**

*No algorithm. No feed manipulation. Just people.*

Zeezu is a modern, highly-customizable social platform built to return power to the user. Claim your **ZID**, dive deep into intense personal identity customization (from 3D profile cards to profile anthems), and connect purely on your own terms.

## ✨ Features

- **Deep Identity Customization**:
  - Theme presets & detailed custom color palettes (MySpace Customization Engine).
  - Profile Anthems (custom theme tracks).
  - Vibe meters (Trust, Cool, and Sexy status bars).
  - Live 3D ProfileCard previews synced with your identity.
  - Highly configurable wallpapers, backgrounds, and social links.
- **Social & Connection**: 
  - ZeeWall: A global chronological feed with vote systems, sharing, embeds (YouTube, Spotify, etc.), GIFs, and polls.
  - Core 8 Management & Friend System.
  - Direct Messaging & "Buzz" Messaging.
  - Realtime Notifications with Toast + Bell alerts.
  - Search & Discovery engine.
- **Passwordless Auth**: Secure magic link login.
- **Pure Social**: A return to chronological, chronological-like, pure social interaction.
- **Enclave V23**: Private spaces and exclusive features.
- **Modern Tech Stack**: Ultra-performing, sleek design language utilizing a bleeding-edge web stack.

## 🚀 Getting Started

First, install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the app running live.

### Environment Setup

Create an `.env.local` file at the root of the project to add your Supabase credentials.

```env
NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
```
